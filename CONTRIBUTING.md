# Contributing to Bonkproof

Thanks for your interest in Bonkproof.

The project is intentionally small and early-stage. Contributions are welcome, but keeping the scope focused matters more than adding lots of features quickly.

## Before larger changes

Please open or comment on a GitHub Issue before starting a larger feature. Small fixes, documentation improvements and tests can go straight to a pull request.

## Development principles

- Keep the basic GPX workflow usable without an account.
- Prefer local/browser-side processing where practical.
- Prefer open data sources and document external service dependencies.
- Do not commit personal GPX tracks, credentials, API keys or other secrets.
- Add or update tests for behaviour changes where feasible.
- Keep changes small enough to review.

## Commit and pull request style

Clear, descriptive commit messages are preferred. Pull requests should briefly explain what changed, why it changed and how it was tested.
